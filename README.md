# OmaShuffle

A different [Omarchy](https://omarchy.org/) theme on every real boot, drawn from a
shuffled deck of themes you pick. Built as a Quickshell shell plugin.

![OmaShuffle picker](screenshots/picker.png)

## What it does

- On each **real boot** (a reboot, or any start where you had to type your
  disk-unlock passphrase), OmaShuffle applies the next theme from your deck.
- The deck is a **shuffled bag**: every theme you picked is used once before any
  repeats, then the bag reshuffles.
- Shell restarts, relogins, `omarchy restart shell`, and resume-from-suspend
  **do not** trigger a switch - only a genuine boot does.
- A fullscreen picker (opened from the Omarchy menu) lets you choose which themes
  are in the rotation, apply any theme on the spot, shuffle now, or turn the
  boot switching off.
- Every switch is a normal `omarchy theme set`, so nothing here is irreversible -
  pick any theme by hand whenever you want.

## Requirements

- Omarchy with its Quickshell-based shell
- `python3` (used once at startup to read this plugin's own small state file
  through a single pinned file descriptor - see "Notes for reviewers")
- Standard Omarchy commands on `PATH` (`omarchy`, `omarchy-shell`,
  `omarchy-notification-send`) - all present on a normal install

## Install

```bash
omarchy plugin add https://github.com/Deunnis/OmaShuffle.git --enable
omarchy restart shell
```

## Using it

Open the picker from the Omarchy menu (**Super + Space**), under
**Style -> Theme Shuffle**. The menu row is added automatically the first time
the plugin loads, and removes itself if you later disable the plugin. You can
also bind a key directly:

```lua
-- ~/.config/hypr/bindings.lua
o.bind("SUPER SHIFT", "T", "omarchy-shell shell toggle io.github.omashuffle")
```

In the picker:

- **Left-click a theme** - apply it now.
- **Right-click a theme** - add or remove it from the rotation (the checkmark).
- **Shuffle now** - jump to the next deck theme immediately.
- **Reshuffle deck** - throw away the current shuffle order and start a new bag.
- **Select all / Select none** - bulk-edit the rotation.
- **Boot shuffle: on/off** - master switch for the once-per-boot behaviour.
- The gear opens a small settings pane: notification on/off, and transparency /
  corner / outline sliders for the picker card.

Until you pick at least one theme, nothing switches - the plugin just shows a
one-time reminder on boot.

## How the deck works

State lives in `~/.local/state/omarchy/io.github.omashuffle/state.json`:

- `pool` - the theme slugs you've put in the rotation.
- `deck` - the remaining shuffled order for the current bag. When it empties, a
  fresh shuffle of `pool` is drawn (and the theme you're already on is pushed
  back so it doesn't repeat immediately).
- `history` - the last 40 themes OmaShuffle applied, with timestamps.
- `lastBootId` - the value of `/proc/sys/kernel/random/boot_id` at the last
  switch. That id is regenerated by the kernel on every boot and is stable
  within a boot, which is exactly the "real boot vs. shell restart" signal.

## Notes for reviewers

- **No network. No privileged calls.** The plugin runs `omarchy theme set`,
  `omarchy-shell`, `omarchy-notification-send`, `cat` on two fixed paths, and
  its own two helper scripts under `bin/`.
- **Theme slugs are validated** (`^[a-z0-9][a-z0-9._-]*$`, no `/`, no `..`,
  length-capped) in `ThemeDeck.js` before ever being passed to
  `omarchy theme set`, on top of that command's own checks.
- **State file read** (`OmaShuffle.qml`, `stateReaderScript`): the file sits in
  `~/.local/state`, so it is read by a short `python3` snippet that opens the
  path exactly once with `O_NOFOLLOW | O_NONBLOCK`, `fstat`s that same
  descriptor to require a regular file, and reads at most `limit + 1` bytes -
  so the amount read is bounded by the read call itself, not by what the path
  claims to be. Writes go through `FileView` with `atomicWrites`.
- **`bin/omashuffle-scan-themes`** only reads `colors.toml` files from the two
  standard theme directories and pulls hex values out of them. It never
  executes anything from a theme.
- **`bin/omashuffle-menu-entry`** adds/removes a single row in
  `~/.config/omarchy/extensions/omarchy-menu.jsonc` (backed up alongside as
  `omarchy-menu.jsonc.omashuffle.bak` before each edit) and only ever reclaims
  a row it owns. Same pattern as the `taxin.cursor-style` plugin.

## Not included

- No theme editing or creation - OmaShuffle only rotates themes that already
  exist. Use `omarchy theme` or a theme-designer plugin for that.
- No scheduling beyond "once per real boot" (no hourly/daily rotation, no
  time-of-day themes).
- No wallpaper-only shuffle - it switches whole themes via `omarchy theme set`.
- No background blur behind the picker card (transparency/corner/outline only).
